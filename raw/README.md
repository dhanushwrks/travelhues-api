# Raw sources (immutable)

Drop curated source material here: API specs, migration notes, infra runbooks, and incident writeups. Agents **read** these files but **never modify** them.

- Reference pattern: [references/llm-wiki-pattern.md](references/llm-wiki-pattern.md) (Karpathy LLM Wiki gist)
- Processed knowledge lives in [`../wiki/`](../wiki/). Follow [`../wiki/SCHEMA.md`](../wiki/SCHEMA.md).
